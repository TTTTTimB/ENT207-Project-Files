# 中英文切换（i18n）

## 使用方式

- **登录页**：右上角「中文 / EN」按钮；
- **登录后**：任意页面右上角同样有「中文 / EN」按钮（顾客端、商户端、管理员工作台通用）。

切换立即生效，覆盖登录、顾客端、商户端、管理员账号管理、室内导航、3D/2D 地图、提示语与错误信息；选择保存在浏览器 `localStorage`（键 `superbrand.lang.v1`），刷新或下次打开保持上次语言，默认中文。

切换时有一小段过渡动画：整页内容淡入并轻微上移（约 380ms），按钮上的「中文 / EN」高亮做一次弹性缩放；系统开启「减少动态效果」时动画自动关闭。

## 覆盖范围

| 区域 | 是否翻译 |
|---|---|
| 登录 / 注册 / 演示账号入口 | ✅ |
| 顾客端：首页、店铺目录、收藏、店铺详情 | ✅ |
| 室内导航：起点/终点面板、楼层/类型筛选、路线摘要、逐步指引、2D/3D 地图切换 | ✅ |
| 商户端：经营总览、店铺分析、趋势、排行 | ✅ |
| 管理员：总览、账号管理、角色与状态 | ✅ |
| 个人信息弹窗、退出登录、演示提示条 | ✅ |
| 店铺分类、铺位描述、设施名（电梯/楼梯/出入口）、SVG 地图静态标注 | ✅ |
| 提示消息、表单校验错误、A* 路线步骤 | ✅ |
| 店铺/品牌名、账号名称等专有名词 | 保留原文（品牌名不翻译） |
| 楼层编号（B1、1F–10F）、金额、数字 | 无需翻译 |

## 实现

| 文件 | 作用 |
|---|---|
| `src/i18n.js` | 中英文字典与 `t()`；`tFacility()` 设施名、`tUnit()` 铺位描述、`translateSvgLabel()` 地图 SVG 文案 |
| `src/LanguageToggle.jsx` | 「中文 / EN」切换按钮 |
| `src/i18n.css` | 登录页/顶栏切换按钮样式 |
| `src/svgI18n.js` | 英文模式下翻译楼层 SVG 里的静态中文标注 |
| `src/routeEngine.js` | 路线摘要与逐步指引使用 `t()`，支持占位符 |
| `src/App.jsx` | 语言状态、顶栏切换、`document.title` 与 `<html lang>` 同步 |
| `src/main.jsx` | 引入 `i18n.css` |

`t()` 以**中文原文为 key**，找不到英文时自动回退中文，因此漏翻不会出现空白：

```jsx
import { t } from "./i18n.js";

<h1>{t("商场首页")}</h1>
<p>{t("共 {v1} 家店铺", { v1: 21 })}</p>
```

新增文案时：在 JSX 中写 `t("中文原文")`，再到 `src/i18n.js` 的 `EN` 字典补一行 `"中文原文": "English"`；带变量用 `{v1}`、`{v2}` 占位。

## 注意

- **内部状态值不要翻译**（例如分类过滤的状态值仍用「全部」，只在按钮显示时 `t(c)`），避免英文模式下筛选条件与数据值不一致；
- 店铺、品牌、用户姓名属于专有名词，保留原文；
- 新增页面或按钮时，先运行一次英文模式（点击「EN」），确认没有遗漏中文；`tests/i18n.test.mjs` 会自动检查字典/toggle 关键接线。

## 测试

```bash
npm run test:sites
```

`tests/i18n.test.mjs` 覆盖：默认中文、英文翻译、占位符插值、设施/SVG 名称翻译、登录页/顶栏切换按钮接线、路线文案与账号页翻译调用。
